# Contributing

The project is early enough that the most useful contributions are corrections to
the research in `notes/` and opinions on the open questions in
`notes/design-notes.md`. Open an issue for either.

Once there is code, pull requests are welcome. Keep changes to one adapter or one
board feature per PR. If you add or change an adapter, update the matching file in
`notes/harnesses/` so the notes stay honest about what is verified and what is
inferred.

Everything here is MIT licensed, and contributions are accepted under the same
terms.
